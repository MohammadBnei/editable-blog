Covers 2026-08-26 through 2026-09-02, across `agent-fleet`, `infra-bootstrap`,
and `editable-blog`. This window overlaps six of seven days with
[yesterday's rundown](/blog/weekly/2026-09-01) — the whole `ukubi-stt` arc,
the GPU scheduling work, and the pgbackrest write-up already got told there.
What follows is what's actually new since that post went out.

## What shipped

**agent-fleet** is where the new material is. Scheduled agents had a dedup
key meant to stop a schedule firing twice while a previous run was still
open — `#245` fixed it getting stuck permanently "open" even after the
blocking session was swept, because the key only cleared on a human's
Archive click, never on retention GC. That shipped, and the same day the
Weekly Rundown schedule itself hit the gap `#245` didn't close: the blocking
session had a dead pod but was never archived, so the key stayed held, and
separately "Run now" was being silently swallowed by that same key. `#246`
closed both, deliberately scoped to schedules only rather than reaching for
pod phase as a general liveness signal. Two PRs to actually fix one bug,
found by hitting it in production on the thing that was supposed to be
reporting on production.

**infra-bootstrap** opened (not yet merged) `#239`: a "bonjour" split into
"bon jour" was first suspected as an STT model-quality problem worth a
correction pass, and turned out to be a client-side bug trimming
SentencePiece's leading word-boundary space. Fixed upstream; the PR mostly
documents the six remedies that were considered and rejected before that.

**editable-blog** was quiet — nothing merged past `#18`, already covered.

## What was decided

Nothing new. No ADR merged in this window that wasn't already reported
yesterday.

## What stalled

- **agent-fleet#227** and **agent-fleet#200** are both still untouched —
  zero comments, no update since filing. `#227`'s own body already argues
  `#200` looks resolved on current main and should just be checked and
  closed. That check still hasn't happened.
- **agent-fleet#59**, the CI-only flaky test, has now been open over four
  weeks with nothing new against it.
- A worker-pod session spent real effort this week working out how to run
  `/dashboard-e2e` without Docker or a `migrate` CLI — seven distinct
  workarounds, logged to the journal. None of it made it into the skill
  itself yet, so the next session pays the same cost to rediscover it.

## What it cost

The real cost this week was the dedup key, and it's worth being honest about
it: `#245` was a considered fix, reasoned through, and it still wasn't
enough — `#246`'s own description says pod phase was deliberately rejected
as a *general* signal in `#245` because it's noisy, then brought back in
`#246` scoped narrowly to schedules, because the narrow case turned out to
be exactly where the gap was. That's not a wrong fix corrected later; it's a
fix that covered one path and got extended once production found the other
one, on the schedule that exists to report on weeks like this one.
