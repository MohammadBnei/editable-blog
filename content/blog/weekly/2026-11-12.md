Window: 2026-11-05 to 2026-11-12. Nearly all the work this week was in `infra-bootstrap`, building the infrastructure for a shared game world. `agent-fleet` merged one fix and opened a security draft. `editable-blog` was quiet: nothing merged, and the one open post ([#29](https://github.com/MohammadBnei/editable-blog/pull/29)) is still waiting for my review.

## What shipped

**infra-bootstrap**

- **The realm exists.** `realm.bnei.dev`, the websocket server for the shared world, now has a registry entry, its own database, ticket-signing keys and a Cilium fence ([#400](https://github.com/MohammadBnei/infra-bootstrap/pull/400)). Its Secret now also carries an HMAC key for voice ids and the owner's subject ([#408](https://github.com/MohammadBnei/infra-bootstrap/pull/408)). The game got its own database user ([#403](https://github.com/MohammadBnei/infra-bootstrap/pull/403)) and its own build runner ([#404](https://github.com/MohammadBnei/infra-bootstrap/pull/404)). Before that runner, the pods sat in `ImagePullBackOff` on an image that had been pushed once, by hand.
- **Visitors can sign themselves up.** `world.bnei.dev` now has local sign-up, owner approval, password reset, and an hourly cleanup of accounts that never verified ([#406](https://github.com/MohammadBnei/infra-bootstrap/pull/406)). Until then the login was fail-closed for anyone who was not a visitor.
- **wedding-2026 is gone** from GitOps, Pigsty, Garage, the runners and RBAC ([#385](https://github.com/MohammadBnei/infra-bootstrap/pull/385)). Deleting it counts as progress. The PR also corrects its own brief: Argo created the namespace with `CreateNamespace`, so pruning will not cascade-delete it, and deleting it stays a manual step.

**agent-fleet**

- [#364](https://github.com/MohammadBnei/agent-fleet/pull/364) added the text for a new error key, `DECISION_CONFIRM_REQUIRED`. The console's error maps are typed to cover every key, so the missing entry failed `svelte-check` and `tsc`, which broke the image build on main. The type did its job. The fix merged six minutes after it was opened and unblocked a release.

## What was decided

All four are still open PRs. None of them is merged.

- **ADR-0070, a Talos pilot** ([#401](https://github.com/MohammadBnei/infra-bootstrap/pull/401), Proposed): a throwaway two-node cluster, so that "drop Proxmox" gets decided from test results instead of estimates. Prod is not touched.
- **ADR-0071, the target platform** ([#410](https://github.com/MohammadBnei/infra-bootstrap/pull/410), draft): four servers, Talos, an HA control plane and HA Postgres, and one registry file per app. It rejects a full CRD, and it rejects a cloud off-site copy in favour of an offline disk that can be up to a month stale. It assumes "Talos first" before ADR-0070, which it sits on, has any result. It is ahead of its own evidence.
- **ADR-0072, self-hosted LiveKit for voice** ([#409](https://github.com/MohammadBnei/infra-bootstrap/pull/409), draft): it opens two more public ports, and ICE gives every player the WAN IP that the origin lock otherwise hides. The price of not sending voices to a hosted SFU.
- **ADR-0060 amendment** ([#398](https://github.com/MohammadBnei/infra-bootstrap/pull/398)): one `trusted` bit is split into two facts, who sent the event and who owns the thread.

## What it cost

The world's sign-in was built three times in three days. [#406](https://github.com/MohammadBnei/infra-bootstrap/pull/406) merged without its last review-fix commit, which then had to land on its own as [#407](https://github.com/MohammadBnei/infra-bootstrap/pull/407): the gates now re-read the user from the database, so Deactivate always wins. The next day, [#411](https://github.com/MohammadBnei/infra-bootstrap/pull/411) reversed #406's decision to refuse admin accounts, because that locked me, the owner, out of my own game. Admins now go to the default flow, with MFA, before any password check. The cost is that the page shows which names are admin accounts. Some of the week went to repairing older breakage. Late-October power outages had caused a Patroni failover, and Pigsty writes had been going to the standby while still reporting success ([#403](https://github.com/MohammadBnei/infra-bootstrap/pull/403)). GitHub forced a runner update, and the old runner deregistered itself and crashlooped ([#402](https://github.com/MohammadBnei/infra-bootstrap/pull/402)). authentik 2026.8 rejected a blueprint that had no `redirect_uris`, so the game got `invalid_client` ([#405](https://github.com/MohammadBnei/infra-bootstrap/pull/405)). And #385 merged with its body still saying "HOLD: do not merge until the owner has confirmed the export", and no comment records that confirmation. The export may well have happened, but the PR doesn't show it.
