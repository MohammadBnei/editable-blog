Covers 2026-09-02 through 2026-09-09, across `agent-fleet`, `infra-bootstrap`,
and `editable-blog`. One day overlaps [last week's rundown](/blog/weekly/2026-09-02) —
`agent-fleet#245` and `#246`, the dedup-key fix, were already told there and
aren't repeated. Everything below is new, and nearly all of it happened
between the afternoon of the 2nd and the night of the 4th; the rest of the
window was quiet.

## What shipped

editable-blog#20 shipped a gated `/linkedin` section — drafts behind
authentik, a copy-for-LinkedIn button, a French translation, the first real
draft. It went out and immediately 404'd. infra-bootstrap#240 diagnosed it as
a missing authentik provider for the host and proposed adding one to the
blueprint. infra-bootstrap#241 disproved that: one `forward_domain` provider
already covers the whole zone, and curl plus the Traefik/authentik logs
showed the actual cause sat in editable-blog itself — `sveltekit-cors`, left
over from the old SSR build, was setting `X-Forwarded-Host` to a literal
`{{ .Host }}` template string, because Traefik v3 doesn't template
`customRequestHeaders` the way v1 did. authentik trusts the header ahead of
it in the chain, looked up an application for that garbage hostname, found
none, and 404'd — closed, but for the wrong reason. The actual fix,
editable-blog#21, was deleting the dead header override; the code that read
it hadn't existed since the `adapter-static` rewrite. #240 closed the same
day it opened.

Also from editable-blog: #19 rewrote the ukubi-stt post after an
architecture interview replaced "cover everything about the service" with an
actual angle, and split `.claude/skills/blog-voice.md` out of three
duplicated copies of the same voice rules.

infra-bootstrap#239 landed the ADR-0048 writeup: a "bonjour" rendered as
"bon jour" during streaming dictation looked like a model-quality problem
first. It wasn't — a test client was trimming every chunk and fabricating
its own separator, destroying SentencePiece's real word-boundary marker. The
ADR explicitly rejects adding a correction model to fix it, on the grounds
that the path is already latency-critical at 560ms.

infra-bootstrap#242 added a Garage bucket for a guest-photo wall at
Mohammad's wedding — real infra for a one-day event, including a S3 region
gotcha (Bun's client defaults SigV4 to `auto`, which Garage rejects).
infra-bootstrap#243, three minutes after #242 merged, reverted an
accidental hitchhiker: #242's branch had been cut from an unrelated,
intentionally-unmerged branch, dragging a registry entry for a service with
no `helm/` directory along with it. Caught and undone before ArgoCD ever
saw it.

## What was decided

ADR-0048, finalized this week: the word-split bug is a client bug, not a
model defect, and a correction-model fix is explicitly off the table for
this path.

## What stalled

agent-fleet had no new merges, PRs, or issues this window past #245/#246,
already reported. Three issues named in the last two rundowns are still
exactly where they were: `agent-fleet#227`, `agent-fleet#200`, and
`agent-fleet#59` all show no update since before last week. `secrets.PAT` is
still the key rotated 2026-07-30. `infra-bootstrap`'s ADR-0037 is still
`Status: Proposed`. None of these moved.

## What it cost

The LinkedIn gate cost a wrong diagnosis before the right one: #240 named
the wrong repo and the wrong fix, and it took reading actual proxy logs in
#241 to rule it out rather than just trying the blueprint change and seeing
if it helped. That's the expensive way to be right, but it's the way that
doesn't ship a second broken fix on top of the first. Everything else this
week was front-loaded into three days — nothing merged, and nothing in the
journal, between the 5th and the 9th.
