Covers 2026-08-25 through 2026-09-01, across `agent-fleet`, `infra-bootstrap`, and `editable-blog`.

## What shipped

**infra-bootstrap** spent almost the whole week building `ukubi-stt`, a GPU-backed gRPC speech-to-text service, from an empty node to two real consumers. GPU scheduling landed on `k8s-worker-01` (ADR-0043, `#210`–`#213`) using containerd's nvidia runtime instead of taints. The service itself (ADR-0044, `#214`) carved a scoped exception into authentik's forwardAuth because a 302 redirect breaks a native gRPC client, made the CUDA startup check a hard assertion rather than a warning (the alternative is `parakeet-rs` silently falling back to CPU), and rejected `sherpa-onnx` after reading its `build.rs` and finding it never actually pulls a GPU build. Model weights went to node-local storage instead of Longhorn or NFS, with CUDA libs baked into the image as an ABI pin (ADR-0045, `#224`). Real-time streaming followed (ADR-0046, `#228`), picking Nemotron over the faster but English-only Parakeet EOU, with lazy model loading so an 8GB card doesn't OOM. By week's end the service was live at stt.bnei.dev and wired to two callers, dream-analyst and agent-fleet, moved onto per-client auth tokens instead of one shared secret.

**agent-fleet** was the other half of that wiring: dictation into the composer (`#242`), proxied through core rather than the browser calling stt.bnei.dev directly — cross-origin cookies don't survive `SameSite=Lax`, and handing a browser an STT bearer token would leak GPU credentials to every dashboard user. Two bugs followed fast: dictated chunks were overwriting each other instead of appending, a stale-closure bug in the `onChange` handler (`#243`); and the mic button looked ready before the audio graph had actually warmed up, eating the first word spoken (`#244`). Separately, `#241` started as "can we restore swept session data?" and the real answer was no — two disks, no backup — so retention became a tunable duration string instead of a compiled constant, and `#239` replaced a hand-enumerated type map in the sidecar with one pinned by reflection over the proto enum, so a forgotten case can't silently drop a message again.

**editable-blog** wrote up last week's Postgres replica incident as a full post, EN and FR (`#17`), then came back and added mermaid diagrams to it plus a new "Diagrams" section in the `new-blog-post` skill, so a post about topology or ordering is now expected to carry one rather than being the odd one out (`#18`).

## What was decided

- **STT proxies through core, never direct from browser to GPU node** (agent-fleet `#242`) — a credential-leak decision, not a convenience one.
- **Node-local model storage over Longhorn/NFS, CUDA libs baked in as an ABI pin** (ADR-0045) — accepts a rebuild-to-update model in exchange for not fighting a network filesystem under a GPU workload.
- **Nemotron over Parakeet EOU for streaming** (ADR-0046) — streaming support beat raw speed.

## What stalled

- **infra-bootstrap#237**, open: ADR-0044's status field said "Proposed" for a day after all six of its decisions were already live and serving traffic. Docs-only, low risk, still unmerged.
- **agent-fleet's `secrets.PAT`** has been expired for five days as of `#236`, blocking releases.
- **`STT_TOKEN_FLEET`** still isn't in Infisical — the dictation feature in `#242` ships inert until it is.
- **ADR-0037**, worker CPU capacity vs. agent-fleet bursts, is still undecided — open since before this window (`#153`).
- No regression tests exist yet for either UI bug found in `#234`/`#236`.

## What it cost

Most of this week's real time went to bugs that looked like one thing and were another. GPU persistence mode was never actually on: the systemd unit invoked `nvidia-persistenced` with `--no-persistence-mode`, so "service active" stayed true while the real mode stayed Disabled — fixed with a drop-in plus an assertion on the actual mode, not the service state (`#212`). A CUDA provider failure blamed as a version mismatch turned out to be two independent Dockerfile bugs, a missing `.so` and `ort-sys` having no CUDA 12 build for Linux at all (`#223`). A 50ms latency spike diagnosed as Freebox hairpin NAT was actually a VPN with a Swiss exit node — the fix (split-horizon DNS) stayed correct, but the reasoning behind it flipped after the fact (`#231`/`#232`). Streaming shipped with three separate latency bugs found by code review rather than testing, plus a self-published RTT number that was itself wrong — a test-harness artifact from opening a fresh TLS connection per chunk instead of reusing one (`#230`). And on the consumer side, dream-analyst's wiring turned up an unauthenticated transcription endpoint and a hardcoded JWT placeholder fallback that publicly exposed production session forgery — not agent-fleet's bug, but agent-fleet's week to find it (`#234`). None of this reverted the service; all of it is why it took a week instead of a day.
