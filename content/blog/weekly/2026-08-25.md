Covers 2026-08-18 through 2026-08-25, across `agent-fleet`, `infra-bootstrap`, and `editable-blog`.

## What shipped

**agent-fleet** closed out the security-hardening push that ran through last week's post. `CoreService` now authenticates a caller with the session's own lease (`#215`), the console federates to authentik OIDC with fail-closed startup (`#216`), e2e previews sit behind the same outpost (`#217`), and once #216 was proven live from real logs, the old shared `apr1` password was dropped (`#220`). Alongside that, the stuck-pod bug from last week's journal entries got a real fix: a session row could claim a pod that Kubernetes had already discarded and never heal, quietly holding one of five concurrency slots hostage (`#236`). The dashboard kept moving too — decision surfaces and a mobile console (`#225`), a background task panel and real diffs (`#238`), a repo clone-cache sync button (`#228`) — and `worker/`'s own test suite finally runs in CI, for the first time (`#205`).

**infra-bootstrap** finished wiring authentik into everything it had promised: ArgoCD (`#182`), Grafana (`#175`), and fleet's own forwardAuth tier (`#190`) all federate login now, on top of `#173` deploying the identity provider itself. `#166` closed out ADR-0040 phase 6 — etcd encryption, audit logging, Cilium encryption. Outside the identity work, `#180` dropped a `KillMode=process` that had been silently orphaning every listener process a build-runner restart left behind, and a side project — `wedding.bnei.dev`, with its own database and build runner — went up (`#192`).

**editable-blog** shipped its own rule change: `#15` rewrote this skill to stop citing PR/commit/line counts as evidence of a good week and write what broke instead — the post you're reading follows it. `#14` made the portfolio bilingual and gave `agent-fleet` and `ukubi-platform` real entries. `#16` made the release workflow atomic so two releases racing each other can't silently lose one.

## What was decided

- **ADR-0041 Decision 3 reversed** (infra-bootstrap, `#191`): `basic-admin-auth` is back in front of the fleet console as a break-glass path. Last week's post recorded it being dropped for OIDC-only; a live authentik-dependency outage during the rollout made "no console at all" a real risk instead of a hypothetical, so single-sign-on convenience got traded back for a fallback.
- **ADR-0056/0057** (agent-fleet, `#221`): "mergeable" is not "compiles." `#215` and `#216` were each green with no textual conflict, GitHub called the merge clean, and `main` didn't build — `#218`'s title ("rename a shadowing variable") undersells that it was a real build break, not a style fix.
- **ADR-0058** (agent-fleet, `#226`): landed with a fix for four separate bugs behind one incident — an answer that couldn't reach a waiting session, a permission-gated pod the reaper ate anyway, a hidden 60-second SDK timeout, and a question list that hid anything past 1000 entries.

## What stalled

- **infra-bootstrap#193**, open: the forwardAuth provider points `external_host` at `fleet.bnei.dev`, which never served the outpost route — every login 404'd, invisible until `wedding-2026`'s admin panel became the first real consumer to hit it.
- **infra-bootstrap#183**, open: the original forwardAuth design proposal, superseded by `#190`'s implementation but never formally closed.
- **infra-bootstrap#153**, open since before this window: the ADR-0037 proposal on worker CPU capacity vs. agent-fleet bursts, still untouched.
- **agent-fleet#239**, open: one of four bugs `#238` found and left unfixed — the sidecar's transcript type maps are incomplete.
- **agent-fleet#227 / #209 / #200**, all filed this window and still open: `/repo-cache` can go stale with nothing to tell a session; `fleet.bnei.dev` is still gated by a shared credential in one place; a worker pod can call mutating dashboard RPCs behind only a CSRF header.
- **editable-blog**: quiet — no open PRs, no open issues.

## What it cost

The authentik rollout produced a real outage, not just the build break above: `#184` wired ArgoCD's admin group from authentik's userinfo claim, and `#187` — titled like a one-line config drop — was actually the postmortem. The in-cluster call to authentik transited Cloudflare, got blocked by Browser Integrity Check, and ArgoCD parsed the resulting HTML error page as JSON and invalidated every session on the strength of it. The `groups` claim had been in the ID token the entire time; the fix was deleting the feature that read it wrong, not adding one. `#188` named this the third time the same failure shape has hit this fleet: trusting a derived report about an artifact — a status field, a log line, a claims field — instead of reading the artifact itself.

The stuck-pod bug (`#236`) had been leaking a concurrency slot for 41 hours before anyone noticed — no error, just a warning repeating on a 60-second loop. And the `basic-admin-auth` reversal above is its own admission: the console spent most of this week with no fallback if authentik went down, and that gap got closed only after living with the risk, not before.
