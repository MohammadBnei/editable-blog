Window: 2026-10-13 to 2026-10-20. Both infrastructure repos were busy. `editable-blog` only took numbers out of the portfolio that nobody had measured ([#27](https://github.com/MohammadBnei/editable-blog/pull/27)).

## What shipped

**agent-fleet**

- **Components authenticate each other.** A pod in another namespace could call the provisioner with no token and get its version back, and `/auth%2Fme` returned the app shell without a login. Now core sends a bearer token, and the provisioner and executor refuse to start without one ([#260](https://github.com/MohammadBnei/agent-fleet/pull/260), [#261](https://github.com/MohammadBnei/agent-fleet/pull/261)). The console checks admin rights on every request ([#258](https://github.com/MohammadBnei/agent-fleet/pull/258)), and ingress NetworkPolicies went on top ([#259](https://github.com/MohammadBnei/agent-fleet/pull/259)). It went out in two parts so no rollout would hit `Unauthenticated` in between.
- **Defined agents**: agents described in reviewed files and read at the release tag, each with its own pod profile ([#262](https://github.com/MohammadBnei/agent-fleet/pull/262), [#263](https://github.com/MohammadBnei/agent-fleet/pull/263)). Their pods hold placeholders, and a proxy swaps in the real credentials behind an egress lock ([#264](https://github.com/MohammadBnei/agent-fleet/pull/264), [#265](https://github.com/MohammadBnei/agent-fleet/pull/265)).
- **Context packs**: rules and skills come from one store and arrive in every pod as a read-only `/genome` ([#272](https://github.com/MohammadBnei/agent-fleet/pull/272)–[#275](https://github.com/MohammadBnei/agent-fleet/pull/275)).
- **Fleet membership comes from GitHub**: a repo is in the fleet while the bot is a collaborator on it ([#271](https://github.com/MohammadBnei/agent-fleet/pull/271)).
- **A commit-msg hook that rewrites the co-author trailer** ([#269](https://github.com/MohammadBnei/agent-fleet/pull/269)), because an agent added a model co-author even though CLAUDE.md forbids it. A written rule lost to a model's habit. The hook does not.

**infra-bootstrap**

- **A platform upgrade run off a reviewed plan** ([#309](https://github.com/MohammadBnei/infra-bootstrap/issues/309)): Argo CD, authentik, NetBird, kube-prometheus-stack, Loki, Grafana 13 and Traefik 42 ([#310](https://github.com/MohammadBnei/infra-bootstrap/pull/310)–[#326](https://github.com/MohammadBnei/infra-bootstrap/pull/326)).
- **mountain.bnei.dev**, a public live 3D view of the cluster that reads PromQL only and gets no RBAC ([#300](https://github.com/MohammadBnei/infra-bootstrap/pull/300), [#304](https://github.com/MohammadBnei/infra-bootstrap/pull/304)). A CI gate came with it: any authentik application without a valid binding now fails the check ([#305](https://github.com/MohammadBnei/infra-bootstrap/pull/305)).
- **Shared notes and a file drop**: SilverBullet, plus a small Go service that only signs URLs, so the bytes skip Cloudflare's 100 MB cap ([#333](https://github.com/MohammadBnei/infra-bootstrap/pull/333), [#341](https://github.com/MohammadBnei/infra-bootstrap/pull/341)).
- **zot had been receiving every secret at the Infisical root**, break-glass tokens included. It now gets its three keys ([#350](https://github.com/MohammadBnei/infra-bootstrap/pull/350)).

## What was decided

- **agent-fleet ADR-0063, context packs**: one place to edit what every agent knows. The cost is that a bad live pack reaches every attached pod at its next warm, with no review.
- **agent-fleet ADR-0075 / infra-bootstrap ADR-0062, a GitHub App instead of the bot's PAT**: no pod holds a real credential. In return, a vault outage stops all fleet work and there is no break-glass.
- **infra-bootstrap ADR-0060, an event bridge on plain Postgres**: pgmq was dropped in review. A Pigsty failover can lose an acknowledged event because replication is async, and that was accepted. Only the database exists so far.
- **ADR-0058, notes canonical in git**: the cost is that a merge conflict halts sync until someone resolves it, on a sync mode upstream calls experimental.

## What stalled

- **Longhorn stopped at hop 2 of 6** ([#331](https://github.com/MohammadBnei/infra-bootstrap/pull/331)), and nothing after 10-16. The plan issues [#307](https://github.com/MohammadBnei/infra-bootstrap/issues/307)–[#309](https://github.com/MohammadBnei/infra-bootstrap/issues/309) are still open.
- [#297](https://github.com/MohammadBnei/infra-bootstrap/issues/297), the duplicate-timestamps alert: drops went to zero on 10-16 and a 24h watch started. Nobody came back to close it.
- [agent-fleet #257](https://github.com/MohammadBnei/agent-fleet/pull/257) (the bridge-events and approval-gated executor ADRs) is open with no review. It is still being amended as the defined-agents work lands, and the deferred split of secrets per component now depends on it.
- [agent-fleet #251](https://github.com/MohammadBnei/agent-fleet/issues/251) is still untouched, for a second week.
- Known gaps the PRs state themselves: `--no-verify` skips the attribution hook. Repos with their own worker image get neither the hook nor `/genome`. Worker pods are not fenced by the new NetworkPolicies. Removing an admin takes up to 12h to take effect.
- Hardware checks still open: memtest on the .165 host, and the physical link on the node whose NIC renegotiated at 100 Mb and froze `/etc/pve` across the cluster ([#332](https://github.com/MohammadBnei/infra-bootstrap/pull/332)).

## What it cost

The Loki upgrade destroyed its own volume. The chart pin and its values are applied by separate Argo Applications. New values on the old chart rendered no StatefulSet, Argo pruned it, and the PVC's `Delete` policy did the rest. The restore came from the 03:00 backup, so logs from 03:00 to 16:11 are gone ([#327](https://github.com/MohammadBnei/infra-bootstrap/pull/327)). The rule that came out of it is to render both mismatched pin/values pairs before merging, and that is why Traefik went out as two PRs. Prometheus went blind again from a second bit-26 flip on the same non-ECC host, and is now pinned off it ([#315](https://github.com/MohammadBnei/infra-bootstrap/pull/315)). After the authentik bump, gunicorn workers segfaulted about four times an hour, and the failed requests never logged as 5xx. A restart cleared it with no root cause found ([#338](https://github.com/MohammadBnei/infra-bootstrap/pull/338)). SilverBullet needed two repairs after its first deploy, one for `lost+found` and one for file ownership ([#334](https://github.com/MohammadBnei/infra-bootstrap/pull/334), [#335](https://github.com/MohammadBnei/infra-bootstrap/pull/335)). In agent-fleet, the CLI version shipped in [#252](https://github.com/MohammadBnei/agent-fleet/pull/252) crashed with `SIGILL` on every run on the Zen 2 worker ([#267](https://github.com/MohammadBnei/agent-fleet/pull/267)). `limits.timeout` killed a session that was in use after 30 minutes, because it had been wired as the pod's lifetime instead of its idle timeout ([#266](https://github.com/MohammadBnei/agent-fleet/pull/266)). The dashboard took three QA rounds ([#254](https://github.com/MohammadBnei/agent-fleet/pull/254)–[#256](https://github.com/MohammadBnei/agent-fleet/pull/256)). The worst finding: the auto-mode confirmation told the user that `git push`, `kubectl` and `curl` would still come to them. They would not.
